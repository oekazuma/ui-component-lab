## Findings considered and rejected

- Hard-coded `rgb(0 0 0 / …)` shadows and dimming (about 20 places): translucent black stays readable in both themes. 030 writes the exception into CLAUDE.md instead of adding tokens.
- `anchor-name` support without `anchor-scope` (Chrome 125–130): each page has one demo frame and list thumbnails never open a dialog, so no dialog can anchor to the wrong frame.
- Runtime cost of the 55 live demos in list thumbnails: only skeleton and back to top do work at mount; 023 gives skeleton a still Thumb.
- `overflow: auto` on the drawer and hamburger menu panels as a focus bug: in Chromium focus still lands on Close. Kept as rule drift only (030).
- Carousel `aria-roledescription="carousel"` in Japanese: the demo's comment records the decision to follow the APG example. A maintainer call.
- Formatter, `.editorconfig`, Playwright browser cache in CI, WebKit/Firefox projects: style holds today; the CI time and cross-engine value are unmeasured.
- Dark palette written twice in `app.css` (could use `light-dark()`), focus-ring declarations copied in 7 places, a `rootPath()` helper, `DesignSystem` union type for alias sources: real but low-leverage tidy-ups; revisit when the next token or alias-source change touches them.
- Button's Agree/Disagree misuse marked `deceptive`: needs the cited Digital Agency guidebook opened to confirm its classification; not planned without that check.
- Mixed-axis key groups (`↓ / →` vs `↑ / ←`), ↓-before-↑ rows in menu and combobox, Japanese spacing before function keys, 「このデモは」 vs 「このデモでは」 openers: CLAUDE.md has no rule for these; not worth a pass on their own.
- `pnpm audit`: no production dependencies; the one low advisory (`deepmerge`, build time) has no fixed version.
- TypeScript 7: wait for svelte-check support before taking the Dependabot PR.
